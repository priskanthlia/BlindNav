BlindNav adalah sistem bantuan berbasis web dan IoT yang dirancang untuk meningkatkan keselamatan pengguna tunanetra.
Aplikasi ini menyediakan:
- Tombol SOS darurat yang terhubung real-time ke pengawas melalui Firebase. 
- Live tracking lokasi pengguna di peta menggunakan Leaflet dan GPS. 
- Monitoring sensor jarak dan status buzzer untuk mendeteksi bahaya di sekitar pengguna. 
Sistem ini bertujuan membantu navigasi, keselamatan, dan respon darurat bagi penyandang tunanetra secara real-time dan terintegrasi IoT.
